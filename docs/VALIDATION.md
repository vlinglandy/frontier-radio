## 验证命令

```sh
python3 tools/verify_sources.py
python3 tools/prepare_voice_fixture.py
./gradlew --gradle-user-home /tmp/ai-radio-gradle \
  :app:assembleDebug :app:testDebugUnitTest :app:lintDebug \
  :app:connectedDebugAndroidTest \
  -PliveFixtures="$PWD/build/source-fixtures"
```

设备测试的翻译用例会下载免费模型，需要网络；系统语音用例要求设备安装中文离线 TTS。Kokoro 用例使用 `tools/prepare_voice_fixture.py` 把经过 SHA-256 验证的解压目录（包括 `.verified` 校验标记）推送到 `/data/local/tmp/ai-radio-model`，用例会复制该夹具，以免 Gradle 重新安装应用后丢失预置模型。缺少中文语音时该用例会明确跳过。应用首次使用也会显示准备指引。

## 需要真机完成的验收

以下尚未确认，不能把模拟器验证当作已通过真机验收：

- **真机锁屏连续播放至少 60 分钟**，包括不同厂商电池管理策略。
- 实际电话来电 / 挂断、蓝牙耳机控制和拔出有线耳机。
- 手机断网后播放完整缓存队列，再恢复网络获取新内容。
- 较低配置手机的翻译速度、发热、耗电和持续运行表现。

程序已配置音频焦点处理、耳机断开暂停、媒体通知、播放与准备期间的唤醒保护，并缓存音频；上述真实硬件表现仍需按以下步骤验证。

## 真机操作步骤

1. 安装 APK，连接 Wi-Fi，准备翻译和中文离线语音，刷新至少 10 条可播内容。
2. 播放后锁屏，记录开始与结束时间，60 分钟后检查消息切换、复习标记、通知控制和播放位置。
3. 点选不同文章、快速连续点选、暂停后重播，检查最后一次选择生效，重播从零开始，播完自动续播；再测试下一条与停止。停止后不自行播放，重新打开应保留进度。
4. 插拔耳机、连接蓝牙耳机并尝试媒体键，接听电话，确认暂停行为。
5. 待当前和后续内容准备完毕后切断网络，检查缓存播放；恢复网络后刷新，确认新消息进入下一条。
6. 在配置中下载自然音色包，测试取消、重试、男女声试听及删除；在真机观察内存、速度和音质。
7. 改变日期、来源和关键词，确认后续播放遵守新配置；只留下一个可用消息，确认持续复习；禁用全部来源，确认显示等待而不是崩溃。

## 自然音色验证

- 中文女声 `zf_001`、男声 `zm_009` 已用实际 Kokoro int8 模型生成 24 kHz WAV，样本分别约 5.65 秒和 5.83 秒；波形 RMS 分别约 2282 和 1788，确认不是空白音频。文件在 `docs/audio/`。
- 回调桥接采用 Kotlin class lambda，保留 JNI 需要的 `invoke(FloatArray): Integer` 方法；初次集成发现的原生兼容问题已修复。
- 模型真实包大小及 SHA-256 已核对；生成测试使用已验证的解压夹具。手机端下载、取消、重试、删除的 UI 和失败处理已实现，但完整下载操作及不同网络切换仍需真机验收。
- 缺少自然音色包时的实际系统语音回退测试已加入最终设备测试。

## 当前边界

- 免费方案提供原文重点抽取与离线机器翻译，没有生成式 AI 深度解读。
- 网页无法读取时回退到订阅摘要；不读取登录或付费内容。
- 无热度指标时采用默认中位排名与时间排序；不虚构官方文章热度。
- 静默等待期间服务可能被系统回收；后台刷新由 WorkManager 调度，不能保证准点，也不会自行开始播放。
- 音频缓存以 200 MB 为清理目标，当前播放及预备文件暂时受保护。
- Lint 的依赖新版本提示不表示功能验证失败；媒体服务保留公开入口以支持系统媒体控制。

构建交付为调试签名 APK，包含多个 CPU 架构的运行库；离线翻译和约 140 MB 的自然音色包独立下载，不包含在 APK 中。APK 签名已使用 Android SDK 的 apksigner 校验。

升级最终结果：31 个 JVM 测试与 13 个模拟器测试全部通过，无跳过或失败；Android Lint 0 错误、17 个警告。警告包括较新依赖版本提示、媒体服务公开入口、备份规则兼容性提示及空资源目录版本提示。
